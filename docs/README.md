# Documents folder

Place the reference documents to be indexed here (`.txt`, `.pdf`, or `.docx`).
Only files at the top level of this folder are indexed; subfolders are ignored.
PDF and DOCX files are converted to `.txt` alongside the originals on first indexing.

The documents used in the paper (Chapter 5 of R. L. Shaw, *Fighter Combat: Tactics and
Maneuvering*, Naval Institute Press, 1985) are copyrighted and are **not** distributed
with this repository. Everything in this folder except this file is ignored by Git.
